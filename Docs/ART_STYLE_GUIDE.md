# Asteria — 美术风格指南

> 状态：Active
> 目标：定义 Asteria 的视觉语言、材质规范、色彩体系和风格约束，确保所有美术资产保持统一风格。

## 1. 视觉身份

Asteria 的视觉身份是：

> 一颗温暖、柔软、有呼吸感的小星球。玩家在上面行走时，能看到地平线的弧度，感受到风和光的变化。

**关键词：** 温暖、柔和、圆润、低饱和、有风感、有光感。

## 2. 渲染管线

- **管线：** URP (Universal Render Pipeline) 17.5.0
- **色彩空间：** Linear
- **目标帧率：** 60 FPS（桌面端）
- **风格：** 三渲二（NPR + PBR 混合）

## 3. 色彩体系

### 3.1 主色调

| 色彩角色 | 色值范围 | 用途 |
|----------|----------|------|
| 天空色 | #A8C8E8 ~ #7BA3C9 | 背景天空、远景 |
| 地面色 | #8B9D7A ~ #6B7D5A | 草地、苔藓、地表 |
| 暖色强调 | #E8C878 ~ #D4A850 | 信标、光源、温暖区域 |
| 冷色强调 | #78B8D8 ~ #5898B8 | 阴影、水域、夜晚 |
| 生命色 | #C8E8A8 ~ #A8C888 | 植物、生物、生态 |
| 纪念色 | #E8D8C8 ~ #D8C8B8 | 建筑、设施、纪念物 |

### 3.2 色彩规则

- 饱和度整体降低 20–30%（对比标准 URP Lit）。
- 高光柔和，不使用锐利镜面反射。
- 阴影偏蓝紫，不使用纯黑。
- 远景雾色与天空色协调。
- 同一星球内色彩种类不超过 6 种主色。

## 4. 材质规范

### 4.1 地表材质

```text
Shader: URP Lit (修改版)
- Base Map: 低饱和色块纹理
- Normal Map: 柔和细节
- Smoothness: 0.1–0.3 (偏哑光)
- Ambient Occlusion: 轻度
- Emission: 无（除非是发光区域）
```

### 4.2 角色材质

```text
Shader: URP Lit (修改版)
- Base Map: 纯色或简单渐变
- Normal Map: 无或极简
- Smoothness: 0.2–0.4
- Rim Light: 启用，柔和边缘光
- Shadow: 偏蓝紫
```

### 4.3 植物/生物材质

```text
Shader: URP Lit (修改版)
- Base Map: 低饱和自然色
- Normal Map: 叶片/毛发细节
- Smoothness: 0.1–0.2
- Wind: 顶点动画（URP 着色器参数）
- Emission: 可选（发光植物）
```

### 4.4 建筑/设施材质

```text
Shader: URP Lit (修改版)
- Base Map: 温暖中性色
- Normal Map: 纹理细节
- Smoothness: 0.3–0.5
- Metallic: 0–0.2 (少量金属点缀)
```

## 5. 光照规范

### 5.1 全局光照

- 使用 URP 的混合光照模式。
- 实时主方向光 + 烘焙环境光。
- 光照探针用于球面动态光照。

### 5.2 方向光

```text
Color: #FFF8E8 (暖白)
Intensity: 1.0–1.2
Shadow Type: Soft Shadows
Shadow Strength: 0.6–0.8
```

### 5.3 环境光

```text
Source: Gradient
Sky Color: #A8C8E8
Equator Color: #C8D8C8
Ground Color: #8B9D7A
Intensity: 0.8–1.0
```

### 5.4 特殊光照

| 光源 | 色温 | 强度 | 范围 |
|------|------|------|------|
| 信标 | #E8C878 (暖黄) | 1.5 | 15m |
| 暖光灯 | #FFE8C8 (暖白) | 2.0 | 20m |
| 发光植物 | #A8E8C8 (冷绿) | 0.8 | 5m |
| 星砂 | #C8B8E8 (冷紫) | 0.5 | 3m |

## 6. 角色设计

### 6.1 比例

- 头身比：1:4 ~ 1:5（可爱但不婴幼儿化）
- 四肢：简洁、圆润
- 面部：大眼睛、小鼻子、简洁表情
- 整体：成年/全年龄中性表达

### 6.2 风格参考

- 轮廓清晰，内部细节简洁
- 使用色块而非复杂纹理
- 表情通过眼睛和嘴型变化
- 动作流畅但不过度写实

### 6.3 禁止

- 写实人体比例
- 过度装饰的服装
- 恐怖、血腥或暴力外观
- 婴幼儿化（大头、超短四肢）

## 7. 环境设计

### 7.1 星球表面

- 球面可见弧度（半径 250–400m）
- 地平线清晰但柔和
- 昼夜线可见但不刺眼
- 装饰物散布均匀，不堆积

### 7.2 区域区分

| 星砂夜谷 | #4A5A6A | 低 | 发光路径、星砂 |

## 8. UI 视觉

### 8.1 风格

- 像旅行手帐和天文仪器的结合
- 不使用厚重战斗 HUD
- 使用简洁线条和柔和色块
- 图标使用线描风格

### 8.2 字体

- 主字体：无衬线，简洁清晰
- 标题字体：可选有风格感的手写体
- 颜色：深灰 #4A4A4A 或暖棕 #6A5A4A

### 8.3 交互反馈

- 按钮悬停：柔和发光
- 点击：轻微缩放
- 完成：柔和粒子 + 音效
- 错误：温和提示，不刺耳

## 9. 粒子与特效

### 9.1 风效

- 草浪：顶点动画 + 粒子
- 风带：半透明流向粒子
- 落叶/花瓣：低密度、柔和飘落

### 9.2 光效

- 信标：柔和光晕 + 上升粒子
- 暖光灯：范围光 + 柔和脉冲
- 极光：半透明带状、缓慢流动

### 9.3 生态效

- 孢子：漂浮、缓慢扩散
- 发光植物：柔和脉冲
- 修复完成：温和爆发 + 音效

## 10. 风格约束

### 10.1 禁止

- 高饱和卡通风格
- 写实 AAA 材质
- 赛博朋克霓虹
- 恐怖/血腥视觉
- 复杂 UI 动画

### 10.2 保持

- 整体低饱和、柔和
- 大形体清楚，远处地标轮廓优先
- 材质层次依靠明暗分区、柔和渐变、细颗粒
- 球面地平线、昼夜线、云层和极光是品牌级视觉资产

## 11. 技术美术规范

### 11.1 性能预算

| 资产类型 | 多边形上限 | 材质数量 | 纹理尺寸 |
|----------|-----------|----------|----------|
| 角色 | 5,000 | 1–2 | 512×512 |
| 建筑 | 3,000 | 2–3 | 512×512 |
| 生物 | 2,000 | 1 | 256×256 |
| 植物 | 500 | 1 | 256×256 |
| 装饰 | 200 | 1 | 128×128 |

### 11.2 LOD

- 角色：2 级 LOD（近距离 + 远距离）
- 建筑：2 级 LOD
- 生物：2 级 LOD
- 植物/装饰：1 级（使用 Impostor 或直接剔除）

### 11.3 着色器

- 使用 URP Lit 着色器的修改版
- 不编写自定义着色器（除非必要）
- 使用 Shader Graph 修改 URP Lit 参数
- 顶点动画使用 URP 着色器参数
