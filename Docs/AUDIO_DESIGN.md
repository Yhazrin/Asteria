# Asteria — 音频设计指南

> 状态：Active
> 目标：定义 Asteria 的音频风格、音效分类、音乐策略和实现规范，确保音频体验与视觉风格一致。

## 1. 音频身份

Asteria 的音频身份是：

> 温暖、有风感、有空间感。玩家能通过声音感知星球的大小、风的方向、生物的位置和社区的氛围。

**关键词：** 温暖、风感、空间感、自然、柔和、有节奏。

## 2. 音效分类

### 2.1 环境音

| 类别 | 描述 | 触发条件 |
|------|------|----------|
| 风声 | 持续背景风声，随高度和位置变化 | 始终播放 |
| 草浪 | 植被随风摆动的声音 | 在风之草原区域 |
| 水声 | 溪流、喷泉、雨滴 | 在水域附近 |
| 冰裂 | 冰面开裂、热泉冒泡 | 在浮冰潮汐星 |
| 孢子 | 漂浮孢子的轻微嗡鸣 | 在花粉云庭 |
| 机械 | 齿轮转动、能量流动 | 在失落机械星 |

### 2.2 交互音效

| 类别 | 描述 | 触发条件 |
|------|------|----------|
| Observe | 发现新事物的清脆提示 | 完成观察 |
| Restore | 修复完成的和谐音 | 完成修复 |
| Cooperate | 同步完成的共鸣音 | 双人同步 |
| 工具使用 | 各工具独特音效 | 使用工具 |
| 拍照 | 快门声 + 确认音 | 拍照 |
| 赠礼 | 柔和赠送音 | 赠送物品 |

### 2.3 角色音效

| 类别 | 描述 | 触发条件 |
|------|------|----------|
| 脚步 | 根据地表材质变化 | 移动 |
| 跳跃 | 轻盈起跳 + 着地 | 跳跃 |
| 滑翔 | 风声 + 布料声 | 滑翔 |
| 受寒 | 颤抖、喘息 | 低温状态 |
| 迷失 | 方向感丧失的音效 | 迷失状态 |
| 救援 | 被救援的确认音 | 被队友救援 |

### 2.4 生物音效

| 类别 | 描述 | 触发条件 |
|------|------|----------|
| 好奇型 | 友好叫声、靠近声 | 主动靠近 |
| 胆怯型 | 警觉叫声、逃离声 | 保持距离 |
| 群居型 | 群体叫声、移动声 | 受整体状态影响 |
| 共生型 | 和谐共鸣声 | Restore 后出现 |
| 引路型 | 引导叫声、方向提示 | 跟随声音或动作 |
| 扰动型 | 干扰声、变化声 | 改变工具/天气 |

### 2.5 UI 音效

| 类别 | 描述 | 触发条件 |
|------|------|----------|
| 按钮点击 | 柔和点击 | 按钮交互 |
| 菜单打开 | 轻盈展开 | 打开菜单 |
| 菜单关闭 | 轻盈收起 | 关闭菜单 |
| 成就 | 温暖提示音 | 完成目标 |
| 错误 | 温和提示 | 操作失败 |
| 通知 | 轻柔提示 | 新消息 |

## 3. 音乐策略

### 3.1 音乐风格

- **整体风格：** 环境音乐 + 轻旋律
- **乐器：** 钢琴、弦乐、木管、环境合成器
- **节奏：** 慢速到中速，不使用快节奏
- **情绪：** 温暖、好奇、宁静、偶尔紧张

### 3.2 场景音乐

| 场景 | 音乐特征 | 情绪 |
|------|----------|------|
| 家园日常 | 轻柔钢琴 + 环境音 | 温暖、舒适 |
| 远征开始 | 轻快弦乐 + 风声 | 好奇、期待 |
| 探索中 | 环境合成器 + 自然音 | 神秘、宁静 |
| 天气事件 | 低沉弦乐 + 风声加强 | 紧张、但不恐怖 |
| 修复完成 | 和谐弦乐 + 钢琴 | 成就、满足 |
| 返家 | 熟悉旋律变奏 | 温暖、归属 |
| 社区活动 | 轻快节奏 + 多乐器 | 欢乐、社交 |

### 3.3 音乐过渡

- 使用淡入淡出，过渡时间 2–4 秒
- 不使用突兀切换
- 音乐层叠加：基础层 + 情绪层 + 事件层
- 优先使用环境音而非音乐填充

## 4. 空间音频

### 4.1 3D 音效

- 所有环境音和交互音效使用 3D 空间化
- 衰减模型：对数衰减
- 最大距离：根据物体大小调整
- 遮挡：使用简单射线检测

### 4.2 球面音频特殊处理

- 风声方向基于球面方向，不使用平面方位
- 远距离队友方向基于大圆最短路径
- 极点附近的音频过渡要平滑
- 昼夜线附近的音效变化要自然

### 4.3 音频区域

| 区域 | 背景音 | 音量 | 特殊处理 |
|------|--------|------|----------|
| 风之草原 | 风声 + 草浪 | 0.6 | 风向变化 |
| 雾声森林 | 低沉环境 + 水滴 | 0.5 | 低能见度音效 |
| 星砂夜谷 | 夜间环境 + 星砂 | 0.4 | 夜间音效 |
| 家园 | 温暖环境 + 社区声 | 0.5 | 随时间变化 |

### 5.3 音频格式

| 类别 | 格式 | 采样率 | 位深 | 声道 |
|------|------|--------|------|------|
| 音乐 | WAV/OGG | 44.1kHz | 16bit | 立体声 |

## 6. 音频与游戏事件

### 6.1 事件导演音频

| 阶段 | 音乐层 | 环境音层 |
|------|--------|----------|
| Arrival | 基础探索层 | 轻风声 |
| Invitation | 好奇层叠加 | 生物叫声 |
| Complication | 紧张层叠加 | 风声加强 |
| Pressure | 压力层叠加 | 极端天气音 |
| Resolution | 解决层叠加 | 恢复音效 |
| Aftermath | 温暖层叠加 | 平静环境 |

### 6.2 居民音频

| 状态 | 音效 |
|------|------|
| 日常活动 | 轻微脚步 + 环境互动 |
| 社交互动 | 对话声 + 笑声 |
| 冲突 | 紧张对话声 |
| 独处 | 轻声哼唱或自言自语 |
| 惊喜 | 惊叹声 |

## 7. 性能优化

### 7.1 音频源数量限制

| 类别 | 最大同时播放数 |
|------|---------------|
| 音乐 | 2 (基础层 + 叠加层) |
| 环境音 | 4 (不同区域) |
| 交互音效 | 8 |
| 角色音效 | 12 |
| 生物音效 | 16 |
| UI 音效 | 4 |

### 7.2 音频压缩

- 音乐：使用 OGG Vorbis 压缩
- 音效：使用 ADPCM 压缩
- 环境音：使用 OGG Vorbis 压缩
- 内存预算：总音频资产 < 100MB

### 7.3 音频优先级

| 优先级 | 类别 | 说明 |
|--------|------|------|
| 最高 | 音乐 | 始终播放 |
| 高 | 交互音效 | 玩家操作反馈 |
| 中 | 环境音 | 空间氛围 |
| 中 | 角色音效 | 角色状态反馈 |
| 低 | 生物音效 | 背景生命感 |
| 最低 | UI 音效 | 界面反馈 |
