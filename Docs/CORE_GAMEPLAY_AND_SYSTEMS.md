# Asteria — 核心玩法与系统

> 状态：Canonical  
> 目标：把“球面探索、朋友生活模拟、多人轻生存”拆成可实现的系统闭环。

## 1. 三层循环

### 1.1 每分钟循环

```text
移动 / 观察地平线
→ 发现生物、居民、线索或危险
→ Observe / Care / Restore / Cooperate
→ 获得即时反馈
→ 路线、环境或人物状态发生变化
→ 前往下一个兴趣点
```

要求：玩家每 30–90 秒至少获得一种反馈：新视野、角色反应、图鉴、工具用途、环境变化或社交事件。

### 1.2 单局远征循环

```text
家园出现愿望或线索
→ 选择目的地、工具和同行星友
→ 2–4 人登陆远征星球
→ 探索并建立临时安全网络
→ 天气 / 生态事件升级
→ 完成核心目标或主动撤离
→ 固定本局发现
→ 返回家园触发居民后续
```

目标时长：20–40 分钟。允许中途撤离，不把“打满一局”变成强制劳动。

### 1.3 长期循环

```text
远征带回发现与人物线索
→ 家园新增居民、设施或生态展示
→ 星友关系与日程产生新故事
→ 新故事解锁更特殊的远征动机
→ 社区形成独有历史
```

## 2. 玩家动作语言

Asteria 的动作应少而有组合性。

| 动作 | 核心作用 | 单人表现 | 多人扩展 |
|---|---|---|---|
| Traverse | 行走、跑、跳、滑行/滑翔 | 读地形和地平线 | 跟随、救援、接力 |
| Observe | 识别与记录 | 图鉴、线索、声音 | 多角度观察、共享线索 |
| Care | 安抚、喂养、照料、陪伴 | 改善生物/居民状态 | 分工保护、引导群体 |
| Restore | 修复装置和生态节点 | 改变局部环境 | 多人同时操作、搬运组件 |
| Cooperate | 共同完成空间任务 | NPC 可提供替代协助 | 远距离同步、角色分工 |
| Place | 放置受限痕迹和临时工具 | 路标、灯、照片 | 形成队伍安全网络 |
| Socialize | 表情、对话建议、合影、赠礼 | 影响星友关系 | 玩家共同制造社交场景 |

首版不要加入复杂武器动作树。危险主要通过移动、判断、照料、工具与协作解决。

## 3. 事件型轻生存

### 3.1 生存资源

不使用长期饥饿/口渴。远征只保留三类易懂资源：

- **光**：照明、驱散黑暗生物、标记路线。
- **温度/庇护**：只在特定天气窗口生效，通过篝光、避难点和抱团恢复。
- **工具能量**：支持观察、修复和信标；可在生态节点补充。

资源应共享或可快速转移，鼓励合作而非争抢。

### 3.2 压力状态

采用短时状态而非角色死亡：

- 迷失：地图与队友方向信息减弱
- 受寒：移动变慢，靠近光源恢复
- 孢子影响：视听提示失真，需要队友引导
- 疲惫：无法冲刺，可在安全点快速恢复
- 失衡：极端天气下更易滑落，但可被队友拉回

状态结束后不留下长期数值伤害。

### 3.3 失败与救援

- 玩家倒下后进入“等待救援”而非死亡。
- 队友可现场协助；超时则由家园信标回收。
- 全队撤离仍保留已固定的观察记录和关键剧情。
- 未固定的临时采集物只损失一部分。
- 不掉装备、不降低角色等级、不清空家园。

## 4. 工具系统

玩家携带 2 个主动工具 + 1 个公共信标，避免背包管理压过探索。

首批工具候选：

| 工具 | 用途 | 球面价值 |
|---|---|---|
| 共鸣镜 | 扫描声音、生命和遗迹信号 | 可越过地平线显示模糊方向 |
| 风帆 | 滑翔、借全球风带移动 | 利用纬度和天气路线 |
| 暖光灯 | 建立短时安全区 | 形成绕星球的灯链 |
| 修复束 | 修复节点、稳定地表 | 多人叠加提高效率 |
| 牵引绳 | 救援、搬运、连接队友 | 极点和陡坡协作 |
| 生态瓶 | 暂存种子或小型生物 | 返家后影响生态展示 |

工具升级提供新观察方式和组合，不提供纯伤害/护甲数值膨胀。

## 5. 受限建设

### 5.1 家园建设

采用预设锚点 + 模块化设施：

- 居民小屋
- 共享厨房
- 观测台
- 温室
- 广场
- 工坊
- 交通/风帆塔
- 纪念馆

每个设施必须至少改变一项居民行为：日程、聚会、职业、关系事件或愿望池。

### 5.2 远征临时建设

只能放置有限工具：

- 信标
- 暖光灯
- 临时绳索点
- 小型避难罩
- 观察标记

数量由 `TraceLimitsConfig` 或后续配置控制；离开远征后自动清理，避免世界垃圾化。

## 6. 资源与经济

### 6.1 资源分类

- **知识**：观察记录、生态数据、地图线索；通常永久保留。
- **活性材料**：用于修复和设施建造；种类少、可再生。
- **记忆物**：照片、声音、纪念物；用于社交与展示。
- **邀请线索**：用于结识新星友，不做随机抽卡。

### 6.2 反刷取原则

- 同类基础资源不设计数百个堆叠数量。
- 重复探索提供不同事件和人物组合，而非单纯提高掉率。
- 重要解锁来自“完成一种经历”，不是收集 999 个材料。
- 资源不足应引导换路线、寻求居民帮助或完成小目标，不要求重复劳动数小时。

## 7. 星球事件导演

每局由事件导演按阶段推进：

1. **Arrival**：天气温和，建立方向感。
2. **Invitation**：出现多个可选目标。
3. **Complication**：生态或人物行为制造意外。
4. **Pressure**：天气/环境进入生存窗口。
5. **Resolution**：完成修复、救援或主动撤离。
6. **Aftermath**：生成远征摘要与家园后续种子。

导演只组合预制事件模块，不在运行时生成不可测试的任意剧情。

## 8. 记忆与故事成果

每次远征结束生成一张“共同回忆卡”：

- 参与玩家与同行星友
- 到访星球和天气
- 关键发现
- 谁帮助了谁
- 选择了哪种结局
- 一张自动构图照片或玩家选图
- 可能触发的居民后续

回忆卡进入家园纪念馆，也成为星友未来对话和关系判断的输入。

## 9. 首个完整垂直切片

### 内容

- 家园：1 个广场、2 名星友、1 个愿望事件
- 远征：当前球体升级为“风之草原”
- 交互：Observe 风铃石、Restore 风塔、Cooperate 双人共鸣门
- 生存：一场 3 分钟风暴
- 工具：共鸣镜、暖光灯
- 建设：家园观测台固定锚点
- 结算：带回风铃种子，触发星友聚会

### 验收

- 单人可完成，但双人明显更顺畅、更有趣。
- 15–25 分钟内经历探索、意外、压力、解决、返家五个段落。
- 远征结果对家园产生可见变化。
- 星友至少自主触发一次玩家未直接点击安排的互动。
