# Asteria — 开发路线图 V2

> 状态：Active  
> 基线：当前 `SphereMoveDemo` 已具备球面移动、散布、Observe 和内存图鉴。

## 0. 路线图原则

- 每阶段必须交付一个可以 Play 的垂直切片。
- 先让系统互相产生故事，再扩数量。
- 每次只引入一个主要风险：存档、居民、远征流、压力、建设、联机依次推进。
- 不在同一阶段同时重构目录、替换输入、重写相机并接入网络。
- 任何阶段失败后，上一阶段仍应可运行。

## Milestone A — 固化当前 Observe 基线

### 目标

把现有 Demo 从“可玩代码”变成可靠起点。

### 任务

- [ ] 更新 `PROJECT_AUDIT.md` 的过时状态
- [ ] 为核心运行时脚本增加第一批 asmdef
- [ ] 增加球面重力、Observe 单次解锁的 EditMode/PlayMode 测试
- [ ] 抽取 `IPlayerInputSource`，但继续使用旧 Input Manager 适配器
- [ ] 为发现数据增加稳定 ID 校验
- [ ] 保留 Editor Upgrade 工具并记录幂等性要求

### 验收

- Unity 6 当前版本打开无 Console Error
- 玩家可绕球、穿越两极，W 不原地自旋
- 8 个 Observe 点可正常记录且不重复计数
- 批处理重建场景后结果一致

### 明确不做

居民、存档、联机、天气、正式 UI。

---

## Milestone B — 可保存的家园雏形

### 目标

首次建立“远征外的长期空间”。

### 任务

- [ ] 新建 `Bootstrap` 与 `HomePlanet` 场景
- [ ] 建立 `GameBootstrap` 组合根
- [ ] 建立纯 C# 存档 DTO、JSON 存档和 schemaVersion
- [ ] 将 `DiscoveryJournal` 接入 `IDiscoveryRepository`
- [ ] 家园放置 1 个观测台锚点
- [ ] 从家园进入现有远征球，再返回家园
- [ ] 返回后在观测台展示已发现的风铃石

### 验收

- 退出游戏再进入，发现记录仍存在
- 家园→远征→家园场景流可重复 5 次
- 存档损坏时能回退到备份，不覆盖好档

### 风险

场景生命周期与静态单例残留。此阶段优先清理，不加居民 AI。

---

## Milestone C — 两名会生活的星友

### 目标

证明社会模拟不是对话框，而是空间中的自主行为。

### 任务

- [ ] `ResidentDefinition`、`ResidentState`、`PersonalityState`
- [ ] 2 名星友 Prefab 与数据
- [ ] 球面路网节点和最短路径原型
- [ ] 起居、广场、观测台三个日程目的地
- [ ] 1 个自主日常事件
- [ ] 1 个玩家建议选项
- [ ] 关键互动写入 `MemoryRecord`

### 验收

- 不操作 10 分钟，居民能够完成日程并至少互动一次
- 重启后居民身份、关系和关键记忆保留
- 极点附近移动不翻转、不穿入星球

### 明确不做

完整聊天生成、恋爱系统、几十名居民、复杂 NavMesh。

---

## Milestone D — 家园愿望连接远征

### 目标

形成第一个“人物动机 → 远征 → 家园后续”闭环。

### 内容

- 星友提出“想听完整的风铃石声音”
- 玩家从家园出发前往风之草原
- 远征记录风铃石并带回种子
- 家园观测台/风铃设施解锁
- 两名居民触发聚会或关系变化

### 系统

- [ ] 愿望模板
- [ ] 远征定义与结算 DTO
- [ ] 共同回忆卡
- [ ] 事件 FollowUpSeed
- [ ] 家园设施固定锚点

### 验收

- 15–20 分钟内完成完整闭环
- 返家后有可见环境变化与人物反应
- 同一结果不会重复结算

---

## Milestone E — Restore + 事件型轻生存

### 目标

让远征出现压力与合作价值，但不变成数值劳动。

### 内容

- 修复一座风塔
- 远征中段触发 3 分钟全球强风
- 玩家使用暖光灯/信标建立安全路线
- 倒下后可被救援或信标回收

### 系统

- [ ] `InteractionInstance` 状态机
- [ ] Restore 多阶段交互
- [ ] PressureDefinition 与事件导演最小版
- [ ] 受寒/失衡中的一个状态
- [ ] 临时工具放置与上限
- [ ] 远征检查点

### 验收

- 单人可完成，双人设计明显更流畅
- 没有饥饿、口渴、装备耐久和死亡掉落
- 风暴结束后角色完全恢复，不留长期惩罚

---

## Milestone F — 固定节点式社区建设

### 目标

建设真正改变居民生活，而不是只放装饰。

### 内容

- 观测台、共享厨房、风铃广场三个设施
- 6 个 Large/Medium 锚点
- 建设前后居民日程和事件池变化

### 系统

- [ ] BuildAnchor
- [ ] FacilityDefinition / FacilityState
- [ ] 预览、旋转、确认、撤销
- [ ] 权限接口，为联机预留
- [ ] 设施使用点和居民预约

### 验收

- 建设一个设施后，至少新增一条居民日程和一个事件候选
- 不支持任意墙体、体素挖掘和无限堆叠
- 存档恢复后设施和居民引用完整

---

## Milestone G — 首个 2 人联机切片

### 目标

验证球面运动、交互、事件和重连的网络风险。

### 前置门槛

- 单机完整闭环稳定
- 存档和权威接口已抽离
- 核心玩法不直接依赖具体网络 SDK

### 任务

- [ ] 评估并安装兼容版本 Netcode for GameObjects
- [ ] Host + Client 玩家同步
- [ ] 专用球面 Transform 校正（必要时）
- [ ] Observe/Restore 权威请求
- [ ] 临时工具同步
- [ ] 阶段快照与 30 秒重连
- [ ] 好友房间最小 UI

### 验收

- 两端穿越极点不爆转
- 一次交互只由主机结算一次
- 客户端重连后恢复远征状态
- 关闭联机后单机仍正常运行

---

## Milestone H — Cooperate 与多人故事

### 目标

让多人不是“同行观看”。

### 内容

- 星球两侧双极共鸣机关
- 分头观察并合并线索
- 玩家救援记录进入共同回忆卡
- 返家后居民提及谁帮助了谁

### 验收

- 至少一个内容无法由单人即时完成，但 AI 同行提供可接受替代
- 合作结果影响家园事件，而非只弹奖励
- 2–4 人会话均可结算

---

## Milestone I — 可对外测试 Alpha

### 内容规模

- 1 个家园星球
- 1 个远征原型：风之草原
- 6–12 名星友
- 3 个社区设施
- 12 个社会事件
- 6 个愿望
- 8–10 个远征 POI
- 1 个压力事件
- 1 个 Restore 链
- 1 个 Cooperate 链
- 2–4 人好友联机

### 品质门槛

- 30 分钟内不出现阻断 Bug
- 存档连续升级与备份可用
- 目标平台稳定 60 FPS（按最终硬件档位调整）
- UI、音频和三渲二视觉达到统一风格
- 新玩家无需开发者说明即可完成首次返家闭环

## 里程碑后再考虑

- 更多远征星球原型
- 异步家园参观和创作物交换
- 主机迁移 / Relay / Lobby
- 复杂恋爱、室友和家庭关系
- 角色创作分享
- 更多同行星友
- 跨星球季节与大型节庆

这些内容不得提前挤占首个闭环的完成度。
